Core: Raw Value → Power Level

Foundation for all anvil costs. Raw value = base tier + enchantments. Linear (1:1) identity: powerLevel = rawValue.

Reference: raw 10→PL 10 | 50→50 | 100→100 | 150→150 | 200→200

Branch A: Durability Restored per Repair vs. Enchantment Raw

Formula: durabilityRestored = (minRepair + (maxRepair - minRepair) / (1 + e^(k × (enchantmentPL - x0)))) × vanillaRepairQuantity. Sigmoid shape: slow decrease at low power, steep drop in the middle, asymptote 0.33 at high power. enchantmentPL = enchantmentRaw (identity) — enchantment raw only, excludes base tier. Defaults: minRepair = 0.25, maxRepair = 1.1, x0 = 100, k = 0.025. Cost per repair: fixed at 1 material item and 1 XP level (material PL excluded).

Branch B: Enchant Cost vs. Combined Raw Value

Cost in XP levels when adding an enchantment from a book. Formula: costInLevels = ceil(minCost + (maxCost - minCost) / (1 + e^(-k × (combinedPL - x0)))). Sigmoid: min ~3, max ~50; cost tapers at high power.

Branch C: Combine Cost vs. Total Raw Value (rawLeft + rawRight)

Cost in XP levels when combining two items (e.g., two swords for durability and enchantments). Uses the same sigmoid as Branch B: combinedRaw = rawLeft + rawRight → costInLevels = ceil(minCost + (maxCost - minCost) / (1 + e^(-k × (combinedPL - x0)))). Durability restored uses Branch A formula based on the left item's enchantment PL.
