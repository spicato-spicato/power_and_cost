Power Level Anvil Cost Calculator

Core power level drives repair effectiveness, enchant cost, and combine cost

Core: Raw Value → Power Level

Foundation for all anvil costs. Raw value = base tier + enchantments. Converted via a gradual exponential curve: powerLevel = round(rawValue^0.75). Doubling raw does not double PL — high-tier gear scales more gently.

Reference: raw 10→PL 6 | 50→19 | 100→32 | 150→42 | 200→53

Branch A: Durability Restored per Repair vs. Enchantment Raw

Formula: durabilityRestored = max(0, 1 - enchantmentPL / ceiling) × vanillaRepairQuantity. Scale: 1 = vanilla repair quantity; values < 1 are reduced. enchantmentPL = round(enchantmentRaw^0.75) — enchantment raw only, excludes base tier. Ceiling = 75. Cost per repair: fixed at 1 material item and 1 XP level (material PL excluded).

Branch B: Enchant Cost vs. Combined Raw Value

Cost in XP levels when adding an enchantment from a book. Formula: costInLevels = ceil(round(combinedRaw^0.75) / 10) where combinedRaw = existingRaw + newEnchantRaw. Variables: combinedPL = round(combinedRaw^0.75). The gradual exponential curve compresses high values, lowering costs for high-tier and heavily enchanted gear.

Branch C: Combine Cost vs. Total Raw Value (rawA + rawB)

Cost in XP levels when combining two items (e.g., two swords for durability). Formula: totalRaw = rawA + rawB → combinedPL = round(totalRaw^0.75) → costInLevels = ceil(combinedPL / 10). Symmetric: same total raw yields same cost regardless of split.
